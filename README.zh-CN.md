# 课程实验报告

[English](README.md) | 中文

面向单人课程实验报告的 Cursor 技能，用 XeLaTeX 排版。

按三件事来做。

- **无 AI 痕迹。** 正文是做完题目的学生口吻。句子写完，公式跟在同一句英文里，真值表后面只留一句结论。不加综述，不加题目外的练习，不加收尾议论。
- **简洁。** 答完该题即止。
- **要求齐全。** 讲义里要求作答的每一题都有一节，顺序与讲义一致。字母、联结词、谓词名和真值表行序都沿用讲义。

报告正文为英文。本页是说明的中文版。

## 文件

| 文件 | 作用 |
|---|---|
| `SKILL.md` | 流程与规则 |
| `template.tex` | 封面、页眉、真值表 |
| `template.pdf` | 空白模板示例 |
| `student.md` | 姓名与学号 |
| `notation.md` | 联结词、量词、表格形式 |
| `handwriting.md` | 仅在要求手写时使用的拍照步骤 |

## 用法

把本目录放到 Cursor 会加载的项目技能路径下，然后给出讲义并要求写实验报告。

封面姓名在你替换之前保持 `name`。学号为空，定稿前会先询问，不会编造。在 `report/` 目录用 XeLaTeX 编译两遍。`template.pdf` 的示例封面使用课程号 `COURSE`、作业号 `N`、日期 `1 January 2026`。
